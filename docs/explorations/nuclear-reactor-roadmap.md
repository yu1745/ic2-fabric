# 核反应堆远期规划（不在当前 3D 重制范围内）

前置：`nuclear-reactor-3d-draft.md` 的可见堆芯已落地。以下各项相互独立，可逐项评估。

## 控制棒
新组件，占一格，**吸收**邻接燃料棒的脉冲（与中子反射板相反）。插入深度由红石信号强度 0–15 连续调节，
顶部渲染棒体上下移动。让红石从"全开/全关"变为**连续调功**，可做自动稳温回路。

## 熔毁分级
堆温超过上限时先进入熔毁：最热的组件熔化为"堆芯熔融物"占格并持续产热，数秒内未降温才爆炸。
给玩家抢救窗口，爆炸前有可见的过程。需决定是否改变原版"超温即爆"的硬核规则。

## 容器材质分级
压力容器壁分铁 / 钢 / 铱强化，决定堆温上限加成与爆炸抑制，部分替代隔板。

## 换料机
堆顶门式吊车（动画），配合红石或升级卡自动替换枯竭燃料棒，替代管道/漏斗插槽式换料。

## 更多视觉反馈
- 中子反射板在反射脉冲时边缘闪烁；
- 组件过热损坏迸火花；
- 堆温 > 85% 时观察窗泛红 + 警报音；外壳上方热浪粒子。
